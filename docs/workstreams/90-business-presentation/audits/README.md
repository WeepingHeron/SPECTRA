# Presentation Audit Results

이 폴더는 SPECTRA 발표 자료와 대본에 대한 독립 persona audit 결과를 보존한다.

## 저장 대상

- 스타트업 대표 관점
- 기업 중간관리자 관점
- 우주항공 교수 관점
- 교육 프로그램 강사 관점
- 여러 audit 결과를 종합한 Control Tower 요약

## 파일명

- 개별 평가: `YYYY-MM-DD_<persona>_<deck-version>.md`
- 종합 결과: `YYYY-MM-DD_CONTROL_TOWER_SYNTHESIS_<deck-version>.md`

예시:

- `2026-08-24_startup-founder_pre-h14.md`
- `2026-08-24_aerospace-professor_pre-h14.md`
- `2026-08-24_CONTROL_TOWER_SYNTHESIS_pre-h14.md`

## 상태 경계

- persona audit 점수는 실제 대회 심사 결과가 아니라 모의 평가다.
- audit의 결함·감점 주장은 Control Tower 검토 입력이며 그 자체로 `VERIFIED` 판정이 아니다.
- 각 파일에는 검토한 deck·대본 경로 또는 commit, 평가 기준, persona, 실행일을 기록한다.
- 수정 전·후 결과를 덮어쓰지 않고 별도 파일로 보존한다.
- 고객·심사위원 실명, 연락처, 비공개 원문과 민감 정보는 저장하지 않는다.
